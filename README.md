# Lo'ma – Food Rescue & Surplus Meal Platform
Lo'ma is a full-stack web application designed to combat food waste by connecting local restaurants, kitchens, and bakeries with eco-conscious consumers. The platform allows businesses to sell high-quality, delicious surplus meals and short-expiry food items at a discounted rate—saving great food from going to waste while offering affordable dining options.
### Key Features
- Live Opportunities Grid: Real-time updates showcasing available meals, countdown timers (e.g., "4 mins left"), and remaining quantities.
- Category Filtering: Quick-browse navigation menus to filter meals by category (Pizza, Burgers, Pasta, Seafood, Healthy Options, etc.).
- Dynamic Rescue Checkout: Secure workflow allowing users to easily select items, view discount rates, and "rescue" meals instantly.
- Distance & Location Tracking: Displays precise mileage proximity from the user's location to the partner kitchen or restaurant.
### Tech Stack
- Frontend: React.js, React Router, CSS3 / Modern Tailwind Utility Classes
- State & Tooling: Component-based UI rendering, responsive mobile-first layouts, and integrated package handling
### Getting Started
To get a local copy up and running, follow these simple steps:
1. Clone the repository: `git clone https://github.com/ShiekhWeso/loma_food_waste`
2. Install dependencies:
```
cd loma-food-waste
npm install
```
3. Run the development server: `npm start`
4. Open http://localhost:3000 in your browser to view the application.
